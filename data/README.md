# Data folder

The synthetic transaction stream is generated by the code, so nothing is needed here for the main experiments.

**Optional realism check:** download `creditcard.csv` (ULB credit-card fraud dataset, 284,807 transactions)
from https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud and place it in this folder:

```
data/creditcard.csv
```

The file is not stored on GitHub (about 150 MB, separate licence). Once it is here, the app shows a
"Kaggle credit-card data" option, the notebook runs its last section, and you can run:

```
python run.py experiment --kaggle data/creditcard.csv
```
