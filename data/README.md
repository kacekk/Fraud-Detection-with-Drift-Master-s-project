# Data folder

The synthetic transaction stream is generated by the code, so nothing is needed here for the controlled
experiments. Two public real datasets can be added:

## IEEE-CIS Fraud Detection (main real dataset)

Real e-commerce card transactions from Vesta Corporation (Kaggle, 2019): 590,540 labelled transactions,
about 3.5% fraud, roughly six months. See [`ieee-cis/README.md`](ieee-cis/README.md) for the download steps.
Then:

```
python run.py experiment --ieee
```

and "IEEE-CIS (real e-commerce)" appears as a data source in the app.

## ULB credit-card dataset (optional quick check)

`creditcard.csv` from https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud (284,807 transactions over two
days) placed in this folder. It covers only two days, so it is too short to study drift over months.

```
python run.py experiment --kaggle data/creditcard.csv
```
